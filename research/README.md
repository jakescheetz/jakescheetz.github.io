# research/

Working space for the agent team. Not part of the built site (`build.py` only reads `content/`).

- `BOARD.md` — the shared task board.
- `_template/` — copy to `research/<topic>/` to start a new thread.
- `<topic>/brief.md` — the question, scope, and what "done" means (lead).
- `<topic>/notes.md` — reading notes, one section per source (researcher).
- `<topic>/sources.bib` — verified BibTeX; copy to a post's `references.bib` when writing it up.
- `<topic>/findings.md` — what we learned, with confidence levels (researcher).
- `<topic>/paper.md` — white-paper draft, same front matter as a post so it can move to `content/posts/` (researcher).
- `<topic>/code/` — experiments, data, and figure scripts (developer).
