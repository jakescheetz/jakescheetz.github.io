# Web graphics for the E1 post

Generated by `../../web_figs.py` (standard library only):

    python3 web_figs.py                 # all
    python3 web_figs.py where-they-went # one

| file | what it shows | data |
|---|---|---|
| `route-map` | schematic of the segment, milestones M1–M3, off-route maps (O), Route 22 (D); Pewter onwards greyed out | `pokered/ram.py`, `pokered/detectors.py` |
| `score-vs-progress` | batch 2: score and real progress per checkpoint (score-trained, progress-trained reference, random) | `results/b2/fig1.json` |
| `score-vs-progress-b1` | the same for batch 1 | `results/b1/fig1.json` |
| `where-they-went` | outdoor visit heatmaps at 5M: score-trained (batch 2), capped-score-trained (round 1), random | eval traces in `~/roms/runs/` (position logs) |
| `reward-sources` | where the score came from: by term; off-route share on the original score; grinding share | `results/b2`, `results/r1`, R0 traces |
| `round1-seeds` | round 1, one panel per run: real progress per checkpoint and levelling share | `results/r1/cells.json`, `results/b2/fig1.json` |

Each `.json` holds the numbers drawn, its sources and a suggested caption.

**Style.** Game Boy-ish 4-shade palette on an 8 px grid, with light and dark palettes chosen separately via
`prefers-color-scheme` inside each SVG. Identity never rides on shade alone (labels, markers, dashes, hatching).
Native hover tooltips.

**No ROM-derived pixels.** Nothing here is game art, tiles, sprites or screenshots. Map shapes in
`where-they-went` are only the squares agents stood on (RAM x/y from our traces). The map placement comes from
the coordinate jumps at map edges in those traces, and outlines use map sizes only.

To use one in the post, copy the `.svg` next to `index.md`.
